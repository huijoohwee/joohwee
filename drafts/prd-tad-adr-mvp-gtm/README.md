# Manual planning drafts

This folder is for provisional PRD/TAD/ADR/MVP/GTM drafts before an implementation
owner is chosen. Record the intended repository, source links, continuity ID,
and which claims are proposed or unverified in each draft.

When the owner is known, edit the living specification in that repository's
existing document location. Record the source and successor during handoff;
retire any competing editable copy here. A draft's presence in this personal
workspace does not establish implementation, release, or deployment status.

Existing files in `prd-tad-ard/` have not been moved or classified by this
folder's creation. Resolve each one with its author and implementation owner
before a migration.
