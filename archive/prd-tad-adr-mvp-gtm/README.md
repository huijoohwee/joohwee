# Historical planning snapshots

Use Git history for ordinary revisions. Retain a separate snapshot here only
when an explicit handoff or audit needs the historical bytes. Mark it
`historical` and record its source repository and path, exact source revision,
content digest, successor repository and path, and handoff date.

Snapshots are read-only records. New requirements and decisions belong in the
successor owner. A folder name does not establish that older personal drafts
have been handed off, integrated, or deployed.
